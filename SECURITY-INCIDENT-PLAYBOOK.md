# Playbook de Incidentes de Seguridad de Datos Personales

Ultima actualizacion: 10 de septiembre de 2026.

Este documento no envia notificaciones legales automaticas. Sirve para que el titular y el administrador reaccionen con trazabilidad y asistencia legal.

## Registro minimo del incidente

- Fecha y hora de deteccion.
- Quien detecto el incidente.
- Naturaleza del incidente.
- Sistemas afectados.
- Categorias de datos afectadas.
- Cantidad aproximada de titulares afectados.
- Usuarios/prestamistas afectados.
- Si ERMIF actua como encargado respecto de datos de prestatarios.
- Consecuencias posibles.
- Medidas inmediatas.
- Evidencia conservada.
- Comunicaciones realizadas.
- Responsable interno.
- Fecha y hora de cierre.

## Primeras acciones

1. Contener el incidente.
2. Preservar evidencia sin exponer datos sensibles.
3. Identificar datos y titulares afectados.
4. Revisar si existe obligacion de notificacion a titulares, responsables o ANPD.
5. Si aplica el supuesto legal correspondiente, evaluar el plazo maximo de 48 horas con asesoria legal.
6. Documentar decision, fundamento y comunicaciones.

## Relacion con prestamistas

Si ERMIF actua como encargado respecto de datos de prestatarios y toma conocimiento de un incidente, debe documentar la comunicacion al responsable/prestamista correspondiente para que este evalúe sus obligaciones.
